# GitHub publishing

1. Create repository `AXZ-Cube-Digit-182764125`.
2. Keep README, `.gitignore`, and license generation off.
3. Upload all files in this folder.
4. If hidden files are missing, manually create `.github/workflows/verify.yml` and `.gitignore`.
5. Wait for the `Verify finite certificate` GitHub Action to pass.
6. Publish release `v1.0.0`.
