# Proof

## Statement

For the digit string `182764125`, under the fixed ordered-expression rules in `README.md`, every positive integer from `1` through `4771` is generated by the dynamic-programming recurrence, and `4772` is not generated.

## Exhaustive recurrence

For each nonempty interval `D[i:j]`, the verifier inserts the concatenation leaf `int(D[i:j])`. For every split `i < k < j`, every `a ∈ V(i,k)`, and every `b ∈ V(k,j)`, it inserts exactly:

```text
a + b
a - b
a * b
```

The operation `a - b` is directional. The verifier does not add the swapped branch `b - a` unless a different valid parse places that subtree on the left.

## Soundness

Every generated value corresponds to a syntactically valid ordered expression using each digit in its interval exactly once. This follows by induction on interval length.

## Completeness

Every syntactically valid ordered expression has a root split between two adjacent digit positions. By induction, the left and right subtree values appear in the corresponding interval sets. The recurrence therefore generates the expression value at the parent interval.

## Finite result

The full interval `V(0,9)` has `99,389` unique integer values. The verifier checks every integer from `1` through `4771` is present and that `4772` is absent.

Boundary witness:

```text
4771 = (1+((8+2)*(7+((6+41)*(2*5)))))
```
